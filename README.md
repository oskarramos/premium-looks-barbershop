# Premium Looks Barbershop

Redesigned marketing site for [Premium Looks Barbershop](https://www.premiumlooksbarbershop.com/) in Hemet, CA.

## Preview locally

Open `index.html` in a browser, or from this folder:

```bash
python -m http.server 5173
```

Then visit `http://localhost:5173`.

## What’s included

- Brand-first full-bleed hero using the shop photo
- About, services, Instagram portfolio, grand opening, hours, contact, and map
- Booking link to Squire and phone / email / Instagram contacts
- Responsive layout with subtle motion
